# Open VS Code

Press **alt+x** to open the current project (pi's cwd) in VS Code.

## Usage

- **alt+x** runs `code <cwd>` and shows a notification with the result.

## Requirements

- The `code` command on `PATH` (in VS Code: *Shell Command: Install 'code'
  command in PATH*).

## Install

Part of [dino-pi-extensions](../README.md). Install the whole repo, or just this one:

```bash
pi install /path/to/dino-pi-extensions/open-vs-code
```
